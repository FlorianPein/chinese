# Grammar

The **Grammar** tab of the [app](https://florianpein.github.io/chinese/#grammar) explains Chinese grammar, **one topic per session**, in the order of the HSK levels. Each session explains the topic with example sentences (with audio), then checks it with a few questions. The sentences use words from the [word flashcards](WORDS-PLAN.md): early topics only the most common ones, later topics words further down the list.

Generated by `tools/build.py` from `data/grammar.json` (the order) and `data/grammar/<id>.json` (one file per built topic; the format is in `tools/grammar.py`).
